# laburnumcottageguesthouse.co.uk

Concept home page for Laburnum Cottage Guest House, Mobberley, Cheshire. Prospecting asset by Pixel North, not a live website.

- `index.html` is a single static page (no build step).
- `images/` holds the photos, supplied from the guest house's current website.
- The page carries `noindex, nofollow` so it stays out of search engines. Remove that tag only if the site goes live on the client's domain.
